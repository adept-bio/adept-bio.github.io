# adept-bio.github.io

Project page for **Learning When to Stop: Adaptive Depth for Spatial Gene Expression Prediction from Histology**
(ADePT).

> **Status:** the manuscript is under review. It is not yet accepted or published.

Live page: https://adept-bio.github.io/

## Layout

```
index.html              the whole page
static/css/adept.css    theme
static/js/data.js       values from the paper's tables and figures
static/js/adept.js      interactive figures and charts (plain JavaScript, no build step)
static/images/          figures, expression-map tiles and team photographs
LICENSE.md              licenses for the content, the code and third-party material
```

The page is static. Open `index.html` in a browser to preview it.
